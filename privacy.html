DJ Task Inbox – Privacy Policy

DJ Task Inbox is a private tool used only by Thomas P. Walter (DJ Thomas P. Walter LLC) on his own business Gmail account. It is not offered to the public.

It requests read-only Gmail access. Email data is used only to create task reminders for the account owner. It is never sold, shared, or used for advertising. Short excerpts may be processed by Anthropic's API to decide whether an email needs a reply. Data is stored only on the owner's private device.

Use of data received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoke access anytime at https://myaccount.google.com/permissions. Contact: djthomaspwalter@gmail.com
